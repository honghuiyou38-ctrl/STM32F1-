# 智能灌溉系统
主控芯片：STM32F103C8T6
版本：V1.0
作者：游宏辉
日期：2026‑09‑26

> 配套文档：技术规格与用户手册V1.0、BOM清单、硬件原理图。底层寄存器查阅参考《STM32F103系列官方参考手册与数据手册》。

## 1.项目简介
本系统面向盆栽、小规模温室种植场景，实现环境温湿度、土壤湿度采集；水泵自动灌溉、风扇PWM调速；OLED本地显示；蓝牙串口透传远程控制。
主要功能：
- DHT11采集环境空气温湿度
- ADC采集土壤含水量
- 水泵三模式状态机自动灌溉，支持迟滞防抖动、高空气湿度雨淋锁泵
- 风扇PWM无级调速（10档），温度自动控速
- 0.96寸OLED实时显示全部传感器与设备状态
- 蓝牙串口透传，接收指令完成手动控制、数据查询

## 2.编译环境配置
开发IDE：**STM32CubeIDE**
目标芯片：STM32F103C8T6，Flash 64KB，RAM 20KB
工程入口：根目录 `.project` / `.cproject`
调试器：ST‑Link
编译要点：
1. 使用STM32CubeIDE导入工程根目录
2. 确认目标芯片选择 STM32F103C8T6
3. 调试选项选择ST‑Link Debugger
4. 编译，确保无Error，警告按需评估

## 3.源代码模块说明
工程分层：BSP板级驱动层 + APP业务逻辑层；中断仅置标志，业务全部在主循环运行。


# Hardware：

## 引脚分配表
|引脚|功能|方向|说明|
| ---- | ---- | ---- | ---- |
|PA5|DHT11_DATA|I/O|DHT11单总线数据引脚|
|PA0|SOIL_ADC|输入|ADC1_IN0，土壤湿度模拟采集|
|PB6|I2C1_SCL|输出|OLED I2C时钟|
|PB7|I2C1_SDA|双向|OLED I2C数据，设备地址0x78|
|PA6|FAN_PWM|输出|TIM3_CH1，风扇PWM调速输出|
|PB13|AIN1|输出|TB6612电机驱动输入1|
|PB12|AIN2|输出|TB6612电机驱动输入2|
|PB15|STBY|输出|TB6612待机控制|
|PB10|PUMP_CTRL|输出|水泵继电器，低电平开启水泵|
|PB14|BUZZER|输出|蜂鸣器，蓝牙事件提示|
|PA9|USART1_TX|输出|蓝牙模块TX|
|PA10|USART1_RX|输入|蓝牙模块RX|

## 模块接线说明
|模块|接线|
|---|---|
|DHT11温湿度传感器|VCC‑3.3V，DATA‑PA5，GND|
|土壤湿度传感器|VCC‑3.3V，OUT‑PA0，GND|
|0.96寸OLED(SSD1306)|VCC‑3.3V，SCL‑PB6，SDA‑PB7，GND|
|水泵+继电器|12V电源接继电器输入端；PB10控制继电器线圈；继电器常开触点输出接12V水泵|
|风扇电机(TB6612驱动)|AIN1‑PB13，AIN2‑PB12，STBY‑PB15，PWM‑PA6；电机接TB6612输出端|
|蓝牙串口模块|TXD‑PA10，RXD‑PA9，VCC‑3.3V，GND|
